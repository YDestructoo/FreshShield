# FreshShield

FreshShield is available as an Android APK through GitHub Releases.

## Download

Download the latest Android release here:

**[Download FreshShield](https://github.com/YDestructoo/FreshShield/releases/latest)**

For a specific version, open the [Releases page](https://github.com/YDestructoo/FreshShield/releases).

### Installing the APK

1. Open the latest release.
2. Download `FreshShield.apk` from **Assets**.
3. Open the downloaded APK on your Android device.
4. Allow installation from your browser or file manager if Android asks for permission.
5. Install FreshShield.

## Releases

Release builds are generated automatically by GitHub Actions whenever a version tag such as `v1.0` is pushed.

The APK is attached directly to the corresponding GitHub Release.
